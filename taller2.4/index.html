1. Planteamiento del Problema

El proyecto AeroQuery nace como una propuesta para resolver los desafíos de la gestión operativa en terminales aéreos. Actualmente, los sistemas aeroportuarios requieren manejar un flujo constante y simultáneo de pasajeros, venta de boletos, asignación de personal y logística de equipaje.

Nuestra propuesta consiste en estructurar una base de datos centralizada y normalizada que permita recopilar esta información, sentando las bases para una futura aplicación de escritorio que facilite la extracción de métricas clave para la toma de decisiones gerenciales.

2. Stack Tecnológico

El desarrollo de esta solución está proyectado utilizando el siguiente ecosistema de tecnologías:

  • Microsoft SQL Server Motor de base de datos relacional para el almacenamiento estructurado.
  • C# y Entity Framework Core Lenguaje principal y ORM para el mapeo de la base de datos hacia objetos.
  • Windows Forms (Proyectado) Framework propuesto para la futura interfaz gráfica de usuario.

3. Modelo de Datos

El diseño de la base de datos BDAeropuertoCusco se compone de 13 tablas interrelacionadas, diseñadas para asegurar la integridad referencial:

  • 🏢 Infraestructura: Aeropuerto, Aerolínea, Aeronave, Puerta Embarque.
  • ✈️ Operaciones: Vuelo.
  • 🎟️ Comercial: Pasajero, Boleto, Asiento, Equipaje.
  • 👥 RR.HH: Cargo, Área, Empleado, Vuelo Empleado.

4. Estructura de Consultas Proyectada

El núcleo analítico del proyecto plantea resolver las siguientes interrogantes operativas utilizando LINQ y SQL:

Operaciones Básicas

  • Listado general del catálogo de Aeropuertos.
  • Búsqueda de Pasajeros específicos mediante su número de documento.

Relaciones Intermedias

  • Cruce de Vuelos con sus respectivas Aerolíneas y Aeronaves asignadas.
  • Identificación de Pasajeros con Boletos Activos en el sistema.
  • Directorio de Empleados detallando su Cargo y Área de asignación.
  • Filtro de Vuelos Retrasados y Cancelados para evaluar el impacto en destinos.

Análisis de Datos Complejos (Métricas)

  • Cálculo de la Recaudación por Aerolínea en base al precio de boletos.
  • Ranking de las Rutas más Demandadas (Origen - Destino).
  • Métrica logística del Peso Total de Equipaje agrupado por vuelo.
  • Dashboard de Ocupación: Proyección de la capacidad total de la aeronave versus la cantidad de boletos vendidos.
