1. Planteamiento del Problema

El proyecto AeroQuery nace para resolver los desafíos operativos en terminales aéreos. Actualmente, se requiere manejar un flujo constante de pasajeros, venta de boletos, asignación de personal y logística de equipaje.

Nuestra propuesta consiste en estructurar una base de datos centralizada y normalizada que recopile esta información en tiempo real, permitiendo extraer métricas instantáneas para la toma de decisiones gerenciales.

3. Stack Tecnológico

  • Microsoft SQL Server Motor relacional para almacenamiento estructurado.
  • C# y Entity Framework Core ORM para el mapeo automátizado de DB hacia objetos usando Scaffolding.
  • Windows Forms (UI Moderna) Framework visual proyectado con diseño Dark Mode Split-Screen por código.

4. Estructura de Consultas Proyectada

10 consultas transformadas de C# a SQL altamente optimizado a través de LINQ to Entities para resolver interrogantes operativas.

Nivel 1

Operaciones Básicas

Operaciones de lectura directa y búsqueda de datos.

  • • Listado general del catálogo de Aeropuertos.
  • • Búsqueda de Pasajeros específicos mediante su número de documento.
Nivel 2

Relaciones Intermedias

Navegación de Objetos evitando JOINs manuales.

  • • Cruce de Vuelos con sus Aerolíneas y Aeronaves asignadas.
  • • Identificación de Pasajeros con Boletos Activos.
  • • Directorio de Empleados por Cargo y Área.
  • • Filtro de Vuelos Retrasados y Cancelados.
Nivel 3

Análisis de Datos (Métricas)

LINQ Complejo, estadísticas y proyecciones.

  • • Cálculo de Recaudación por Aerolínea (Precio de boletos).
  • • Ranking de Rutas más Demandadas.
  • • Peso Total de Equipaje logístico por vuelo.
  • • Dashboard de Ocupación: Capacidad vs Boletos Vendidos.
