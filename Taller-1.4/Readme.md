 # 🚗 Mowi App - Arquitectura de Datos

Este proyecto es una representación visual de la arquitectura de datos para Mowi App, una plataforma de movilidad corporativa sostenible.

## 🎯 Sobre el Proyecto
El diagrama ilustra los módulos principales del sistema, incluyendo:
* Empresa (Modelo B2B)
* Usuarios y Conductores
* Solicitudes y Viajes
* Facturación
* Sustentabilidad (Huella de Carbono)

## 🛠️ Tecnologías Usadas
* HTML5
* CSS3 (CSS Grid, Flexbox, Variables nativas)
* Diseño Responsivo (Mobile-first)
